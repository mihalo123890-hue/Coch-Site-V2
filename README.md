# Coch-Site-V2 (Notes — опрос)

Интерфейс первичной версии сайта [mihalo123890-hue.github.io](https://mihalo123890-hue.github.io) с добавлением **6 рекламных блоков** (3 слева и 3 справа столбиком).

🌐 Сайт: **https://mihalo123890-hue.github.io/Coch-Site-V2/**

---

## 🌟 Возможности

1. **Оригинальный интерфейс первичной версии:**
   - Чистый, минималистичный дизайн в стиле `stone` (палитра первичного опросника Notes).
   - Светлая и тёмная тема (переключатель сохраняет выбор в `localStorage`).
   - 23 вопроса в случайном порядке (алгоритм Fisher–Yates).
   - Ведомость «Вопрос — Ответ» с именем участника, кнопками «Скопировать всё» и «Скачать .txt».
2. **6 рекламных блоков (3 слева и 3 справа столбиком):**
   - **Медиа:** поддержка фото (`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`), GIF-анимаций (`.gif`) и видео (`.mp4`, `.webm`).
   - **Подписи:** под каждым фото/гиф/видео размещается отдельная текстовая подпись.
   - **Ссылки для перехода:** при клике на фото/гиф или на текст под ним пользователя перекидывает по указанной ссылке в новой вкладке. Можно задавать как общую ссылку для блока, так и отдельные ссылки для картинки и для текста.
   - **Удобная настройка прямо на GitHub:** все настройки разделены по спискам 1-2-3 слева и 1-2-3 справа.

## ⚙️ Как настроить рекламу прямо на GitHub

Все настройки рекламы находятся в файле **`ads.json`** в корне репозитория (а также продублированы в **`docs/ads.json`**).

Чтобы изменить рекламу:
1. Откройте файл **[`ads.json`](./ads.json)** или **[`docs/ads.json`](./docs/ads.json)** прямо в репозитории на GitHub.
2. Нажмите иконку карандаша ✏️ (**Edit this file**).
3. Измените нужные значения:
   - картинки/гифки 1, 2, 3 слева и справа
   - текст под ними 1, 2, 3 слева и справа
   - ссылки для перехода 1, 2, 3 слева и справа
4. Внизу страницы нажмите зелёную кнопку **Commit changes**.
5. Изменения применятся на сайте!

Настройки разделены на 3 блока слева и 3 блока справа:

  },

    "картинки": [

    ],

## 📁 Как добавить свои фото, видео или GIF-файлы целиком

Вы можете использовать как внешние ссылки (`https://...`), так и загрузить файлы прямо в репозиторий:

1. Откройте папку **[`ads/`](./ads/)** или **[`docs/ads/`](./docs/ads/)** на GitHub.
2. Нажмите **Add file** → **Upload files**.
3. Перетащите свои фото (`.jpg`, `.png`, `.webp`, `.svg`), GIF (`.gif`) или видео (`.mp4`, `.webm`) и подтвердите загрузку (**Commit changes**).
4. В файле `ads.json` укажите имя файла с папкой, например:
   ```json
   "картинки": [
     "ads/my-meme.gif",
     "ads/banner.jpg",
     "ads/promo.mp4"
   ]
   ```

## 🛠️ Разработка и сборка

```bash
npm install        # Установка зависимостей
npm run dev        # Dev-сервер (http://localhost:5173/)
npm run build      # Сборка сайта в docs/ (для публикации на GitHub Pages)
npm run typecheck  # Проверка TypeScript типов
```

---

## 🚀 Публикация на GitHub Pages

Сайт публикуется через встроенный механизм GitHub Pages:
- **Settings → Pages**
- **Source:** Deploy from a branch
- **Branch:** `main` · **Folder:** `/docs`

При каждом обновлении через `npm run build` готовый самодостаточный сайт помещается в папку `docs/index.html`.
