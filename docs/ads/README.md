# Папка для картинок, GIF и видео рекламы

Сюда можно удобно загружать свои изображения (`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`), GIF-анимации (`.gif`) или видео (`.mp4`, `.webm`).

### Как использовать:
1. Загрузите файл в эту папку (например, через веб-интерфейс GitHub: **Add file -> Upload files**).
2. В файле `ads.json` (в корне репозитория или в папке `docs/`) укажите путь к файлу:
   ```json
   "картинки": [
     "ads/my-banner.gif",
     "ads/photo.jpg",
     "https://example.com/banner.png"
   ]
   ```
3. Вы также можете вставлять любые прямые ссылки на картинки или гифки из интернета (`https://...`).
